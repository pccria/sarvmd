## How to Inspect

1. **PDF Files**: Open with any standard PDF viewer or browser (e.g. `evince`, `okular`, Chrome, Firefox). Verify page-to-page visual transitions:
   - Flip from Page 1 to Page 2 in `02_string_quartet_3pages.pdf`: notice how Page 1 has title & composer header, while Page 2's staves shift up to occupy the reclaimed headroom, showing the `- 2 -` header and compact abbreviated instrument names.
2. **Booklet Imposition Files**: Open `07_booklet_string_quartet_4pages_a3_double.pdf`:
   - Sheet 1 (Side 1 / Outside): Left is Page 4 (abbreviated labels, 0 headroom), Right is Page 1 (full title block, 28mm headroom, full instrument names).
   - Sheet 1 (Side 2 / Inside): Left is Page 2, Right is Page 3.
   - Folded down the center tick mark, it forms an authentic, ready-to-staple sheet music booklet.
3. **SVG Files**: Open in Chrome, Firefox, or Inkscape. Inspect layer groups and vector accuracy.
4. **TeX Files**: Inspect the generated LaTeX source. Page 1 contains `\begin{picture}` header block; subsequent pages have zero-headroom staves and running headers.
